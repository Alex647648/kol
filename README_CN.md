## 快速上手

### 1. 准备输入

```yaml
product:
  name: "云南普洱古树茶饼"
  price: "268"
  specs: "357g 茶饼"
  selling_points:
    - "300 年古茶树"
    - "手工揉捻、日光晒青"
    - "自然陈化、越陈越香"
  origin: "云南景迈山"
  craft: "一芽两叶手工采摘、石磨压制"
target_audience:
  age: "30-50"
  profile: "有文化品位的都市白领"
stream_context:
  slot: "爱生活（日常带货）"
  time: "晚间档"
  duration: "12"
```

### 2. 按流程执行

沿 SKILL.md 流水线产出 **七件套**：

```
1. 模式判定    → 知识型带货，三层价值交付设计
2. 人设匹配    → 本场应侧重的人设要素
3. 选品评估    → 五维故事性打分（目标 >= 15/25）
4. 完整文案    → 黄金五步结构的带货文案
5. 直播编排    → 分钟级时间轴 + 每段内容要点
6. 互动预设    → 3-5 条高频弹幕预判 & 回应话术
7. 自检报告    → 四份 Checklist 逐项通过/不通过
```

### 3. 输出示例（文案节选）

> **第一步 — 遗憾共鸣：**
> 「你有多久没有安安静静坐下来了？
> 不看手机，不回消息，不赶 deadline，
> 就只是坐着，看杯子里的热气慢慢升起来，再慢慢散掉。」
>
> **第二步 — 知识锚定：**
> 「公元 862 年，唐人樊绰写了一本《蛮书》，
> 里面第一次记载了云南人采茶、饮茶的方式。
> 从那时候算起，云南的古茶树已经看过一千多年的云雾了。」
>
> **第三步 — 场景描写：**
> 「第二泡出来，颜色像琥珀，
> 端起来先不喝，放在鼻子下面闻一闻，
> 有枣香，有木头的味道，有雨后山里泥土的气息。」
>
> **第四步 — 自然过渡：**
> 「今天这饼茶就是从那样的树上来的。
> 景迈山，海拔 1400 米，茶树和森林长在一起……」
>
> **第五步 — 价值升华：**
> 「268 块钱，你买到的不只是 357 克茶叶。
> 你买到的是一个理由——
> 一个让自己每天慢下来二十分钟的理由。」

## 方法论精华

### 文案黄金五步结构

```
遗憾共鸣 → 个人体验 → 场景描写 → 自然过渡 → 价值升华
```

核心原则：**不提产品功效，用场景和情感让用户自己产生购买欲望。**

### 五大修辞武器

| 武器 | 效果 | 手法示例 |
|------|------|---------|
| 排比句式 | 制造节奏感 + 情绪递进 | 四个「我没有带你去……」→ 一个「但是，我可以……」 |
| 时空跳跃 | 打开想象空间 | 日常场景 vs 远方世界的并置 |
| 知识锚定 | 建立信任 + 深度 | 文明史 → 缩小到个体 → 落到一碗米饭 |
| 自嘲幽默 | 拉近距离、消除推销感 | 自嘲 → 荒诞类比 → 产品植入双关 |
| 感官通感 | 唤醒身体记忆 | 感官对比（燥热出租屋 vs 大兴安岭月光） |

### 柔性转化（拒绝硬逼单）

| 传统硬卖 | 知识型柔卖 |
|---------|-----------|
| 「3-2-1 上链接！」 | 「想试试的朋友可以看看。」 |
| 「最后 5 单！」 | 「268 块 / 泡 40 次 = 每次不到 7 块」 |
| 倒计时 + 背景音乐 | 价值换算 + 场景共鸣 |
| 制造焦虑 (FOMO) | 情感认同 → 主动下单 |

### 故事性五维评分

5 个维度，每维 1-5 分，满分 25：

```
产地故事 + 工艺故事 + 文化故事 + 情感故事 + 感官故事

20-25 分  极度适配    → 优先排期
15-19 分  高度适配    → 正常排期
10-14 分  需要赋能    → 主播需主动创造故事
 5-9  分  低适配      → 建议更换或仅作补充
  <5  分  不适配      → 不上架
```

## 禁忌清单（什么不该做）

- 直接罗列产品参数和功效
- 使用逼单话术（「最后 X 单」「倒计时开始」）
- 贬低竞品
- 引用未核实的知识或错误典故
- 过度煽情、强行催泪
- 播放背景音乐 + 倒计时
- 单品时间低于 3 分钟
- 接入故事性评分低于 10 分的产品
